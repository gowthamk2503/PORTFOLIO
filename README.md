# ⚡ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/gowthamk2503/PORTFOLIO
```

## Navigate to Project

```bash
cd portfolio
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```
